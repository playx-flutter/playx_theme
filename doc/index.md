# Playx Theme

Switch between themes, animate the change, follow the system light/dark mode and
remember the user's choice, with a few lines of code.

- **Theme management**: any number of themes, switch by index, id or `XTheme`.
- **System, light and dark modes**: follow the device or force a mode.
- **Animations**: clipper, fade, scale, slide and a `ThemeData` interpolation.
- **Persistence**: the last theme and mode are saved and restored, in the storage you choose.
- **Custom colors and tokens**: per-theme `PlayxColors` and `ThemeExtension` helpers.
